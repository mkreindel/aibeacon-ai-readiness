# AI Readiness Diagnostic (AI Beacon)

Trabajo Final del Máster en Desarrollo con IA E.2 (BIG school).

Cuestionario web para dueños de pymes: mide su madurez en IA en cinco dimensiones, los ubica en un nivel y genera un informe con casos de uso priorizados. Los resultados quedan como leads para AI Beacon.

Estado: en desarrollo. La especificación del MVP está en [docs/spec.md](docs/spec.md).

Este README se completa con stack, instalación, estructura, funcionalidades, usuario de prueba y enlaces a despliegue, slides y video a medida que avanza el proyecto.
